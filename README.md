# تطبيق غرس الرقمي

بوابة Android موحّدة لأنظمة مدرسة وروضة غرس الحديثة. المشروع يجمع الأنظمة الحالية داخل تطبيق واحد من دون إعادة كتابة منطقها الأساسي.

## الأنظمة المدمجة

- الحضور والغياب: نسخة النظام الحالية 5.3، مع التخزين المحلي وطابور المزامنة نفسه.
- الحصص والتنبيهات: محرك الجدولة الحالي والتنبيهات المحلية الصوتية في الخلفية.
- الألعاب التعليمية: فتح موقع غرس للألعاب بالذكاء الاصطناعي داخل نافذة التطبيق.
- الخطط والتقارير: فتح بوابة الخطط الحالية داخل نافذة التطبيق.
- التذكيرات والمهام: البطاقة والربط جاهزان، وينقص فقط رابط الواجهة الحالية أو ملفاتها.
- إدارة غرس: للمدير فقط؛ إضافة وتعديل وحذف الأكواد، تغيير كود المدير، وفتح حضور أي صف.

## ما بقي كما هو

- مفاتيح التخزين وطابور مزامنة الحضور لم تتغير.
- عمليات Apps Script الخاصة بالحضور لم تُحذف أو يُعدّل معناها.
- منطق جدول الحصص واختبارات الوقت والتنبيهات باقٍ كما كان.
- سجلات الصف لا تُحذف عند حذف كود مستخدم من لوحة الإدارة.

## التشغيل لأول مرة

1. حدّث ملف Apps Script الخاص بالحضور باستخدام `server/Attendance-Code.gs` ثم أنشئ إصدار نشر جديد مع إبقاء رابط `/exec` الحالي.
2. تأكد أن ورقة `Teachers` تحتوي على المدير بالكود `4646` قبل أول تشغيل.
3. ارفع المشروع كاملاً إلى مستودع GitHub جديد.
4. افتح تبويب **Actions** وشغّل **Build Ghars Digital Android**.
5. نزّل `Ghars-Digital-Test-APK` وجربه على الهاتف.

بعد أول تحقق ناجح لكل كود، يستطيع صاحب الكود دخول التطبيق على الجهاز نفسه دون إنترنت. الحضور والحصص يعملان محلياً؛ الألعاب والخطط تحتاجان اتصالاً.

## إعدادات الروابط

جميع الروابط في `www/js/config.js`:

- `attendanceApi`: رابط نشر الحضور `/exec`.
- رابط الخطط لا يُخزّن داخل APK. يُحفظ في Script Properties باسم `GHARS_PORTAL_PLAN_URL`.
- `aiGamesUrl`: موقع منصة الألعاب.
- رابط المهام الاختياري يُحفظ في Script Properties باسم `GHARS_PORTAL_TASKS_URL`.

## هوية تطبيق Google Play

المعرّف المؤقت في `config.xml` هو:

`com.ghars.digital`

يجب تأكيده قبل أول رفع إلى Google Play؛ لا يمكن تغيير معرّف الحزمة بعد نشر التطبيق.

## البناء المحلي

المتطلبات: Node.js 20.17 أو أحدث، Java 17، Android SDK Platform 36 وBuild Tools 36.0.0.

```bash
npm ci
npx cordova platform add android@15.1.0
npm test
npm run build:debug
```

## إنشاء نسخة AAB موقعة

أنشئ مفتاح رفع واحداً فقط واحتفظ به دائماً. على Windows يمكن تشغيل:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\create-upload-key.ps1
```

ثم أضف أسرار GitHub التالية:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

عند توفر الأسرار، ينتج سير العمل تلقائياً ملف `Ghars-Digital-Google-Play-AAB` الموقّع.

## إضافة مشروع جديد لاحقاً

أضف تعريفه إلى `www/js/config.js` ثم بطاقة له في `www/index.html`. المشاريع المحلية توضع داخل `www/modules/`، والمشاريع المنشورة تستخدم رابط HTTPS. بهذه البنية لا يلزم إعادة بناء الأنظمة الأخرى.
