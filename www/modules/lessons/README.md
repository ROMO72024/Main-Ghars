# منبّه غرس للحصص

تطبيق Android أوفلاين لجدولة حصص مدرسة وروضة غرس الحديثة. يحفظ الجدول على الجهاز ويُصدر تنبيهًا صوتيًا قبل الحصة وتنبيهًا آخر عند بدايتها.

## إنشاء ملف APK من GitHub

1. ارفع جميع الملفات إلى المستودع مع الحفاظ على مجلد `.github/workflows`.
2. افتح تبويب **Actions**.
3. اختر **Build Ghars Class Alarm APK** ثم **Run workflow**.
4. بعد اكتمال البناء، نزّل الملف من قسم **Artifacts** باسم `Ghars-Class-Alarm-APK`.

## ملاحظات التشغيل

- وافق على إذن الإشعارات عند التشغيل الأول.
- في Android 13 وما بعده، اضغط **ضبط الدقة** داخل التطبيق وفعّل خيار المنبّهات والتذكيرات إذا ظهر.
- يعتمد التطبيق على وقت وتوقيت الهاتف، لذلك يجب التأكد من ضبط الساعة تلقائيًا.
- لا يحتاج التطبيق إلى الإنترنت بعد تثبيته.
