# قائمة ما قبل رفع Google Play

- تأكيد معرّف الحزمة في `config.xml` قبل أول رفع.
- إضافة رابط الخطط `/exec` إلى Script Property باسم `GHARS_PORTAL_PLAN_URL`.
- إضافة رابط نظام التذكيرات والمهام، أو إبقاؤه معلماً بأنه غير مربوط.
- تثبيت `Attendance-Code.gs` واختبار دخول المدير وإضافة كود تجريبي.
- اختبار الحضور بالإنترنت ثم دون إنترنت ثم عودة المزامنة.
- اختبار تنبيه حصة حقيقية والجهاز مقفل، بعد منح إذن الإشعارات والمنبّهات الدقيقة.
- إنشاء مفتاح رفع واحد وحفظ نسخة احتياطية منه وكلمات مروره.
- إضافة أسرار التوقيع الأربعة إلى GitHub Actions.
- تنزيل ملف AAB الموقّع من Actions ورفعه إلى مسار الاختبار الداخلي أولاً.
- نشر صفحة سياسة الخصوصية بعد إضافة وسيلة التواصل الرسمية.
- تعبئة نموذج أمان البيانات بما يطابق الخدمات المستخدمة فعلياً.
- التقاط صور شاشة من النسخة النهائية بعد تثبيتها على هاتف Android.
- اختبار زر الرجوع، تدوير الشاشة، جهاز ضعيف، Android 7، Android 13، Android 16 إن أمكن.
